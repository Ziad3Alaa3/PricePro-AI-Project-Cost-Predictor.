## 🧠 Model Intelligence
The engine behind PricePro AI is a fine-tuned **Random Forest Regressor** optimized via `GridSearchCV`.

- **Accuracy (R² Score):** `96%`
- **Error Margin (MAE):** `$1,495`
- **Primary Features:** Project Type, Hours, Team Size, Company Size, and Seniority.
